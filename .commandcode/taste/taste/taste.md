# Taste
- When troubleshooting an issue, wants the assistant to go beyond explaining and propose concrete, actionable recommendations (with options ranked by benefit) and offer to implement them — rather than just diagnosing or asking what to do. Confidence: 0.6
- Delegates the actual fixing to the assistant ("it's your job to fix it") — prefers the assistant to take ownership and execute the fix directly, with safeguards (e.g., backing up configs before editing), rather than stopping at recommendations or asking for permission. Confidence: 0.8
- Wants changes to be accompanied by a measurable before/after comparison of their effect (baseline metrics, then post-change verification) so the impact of each fix is evident. Confidence: 0.8
- Maintains a persistent cross-agent memory ("unified-agent-context" / UAC) and expects notable incidents and outcomes to be recorded there (as a `project_state` fact via the repo's `record-fact.mjs` → `context_save`), so context survives across sessions/agents. Confidence: 0.8
- Communicates in terse, imperative commands ("post summary of the incident to uac") and expects the assistant to autonomously discover the relevant conventions and tooling (handoff docs, scripts, configs) and execute without asking clarifying questions. Confidence: 0.7
- Prefers simple, broad storage organization with dedicated categories for ebooks and screenshots while keeping newly downloaded, unsorted content in a separate holding area. Confidence: 0.8
- Prefers Command Code sessions to run with unrestricted `--yolo` behavior by default, rather than manually supplying the flag each time. Confidence: 0.9
- Is interested in using Hermes as a collaborating agent for independently screening local files for migration candidates. Confidence: 0.7
- When asked to "read" or understand a project, expects thorough autonomous reconnaissance — exploring the directory structure and reading all relevant context files (handoff/spec docs, run logs, backups, planning/critic docs, deliverable code) to build a complete picture and synthesize a concise summary, then offer concrete next steps. Confidence: 0.7
